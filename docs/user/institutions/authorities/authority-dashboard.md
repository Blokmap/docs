# Locatiegroepen beheren

Het huidige organisatiedashboard toont geen afzonderlijke ingang voor locatiegroepen. Deze pagina blijft beschikbaar voor bestaande links.

Voor dagelijks beheer gebruik je [Locaties](../locations), [Beheerders](../access/) en [Rollen en rechten](../access/roles) op organisatieniveau. Een locatie koppelen aan een beschikbare organisatie of groep gebeurt via **Locatie-instellingen → Locatiebeheerder**.

Een locatiegroep is niet hetzelfde als een [zone](/user/locations/zones): zones verdelen één locatie in studieruimtes en hebben hun eigen capaciteit en reservatie-instellingen.
