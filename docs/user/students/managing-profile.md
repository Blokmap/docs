# Je profiel beheren

Open je profiel via je profielfoto rechtsboven. Onder **Mijn Profiel** zie je je naam, gebruikersnaam, aantal aankomende reservaties en gereserveerde uren.

## Profielfoto en gebruikersnaam

Via je profielfoto kan je de beschikbare foto-opties openen. Je gebruikersnaam staat onder je naam. Gebruik de kopieerknop ernaast als een beheerder je gebruikersnaam vraagt om je toe te voegen.

## Herinneringen voor reservaties

Bij **Meldingen** kan je e-mailherinneringen voor reservaties aan- of uitzetten. Kies bij **Wanneer wil je een herinnering?** hoeveel tijd vóór de start je een herinnering wil ontvangen: van 30 minuten tot 6 uur. Klik daarna op **Opslaan**.

Controleer de spammap als je geen herinnering ontvangt. Bekijk je reservaties ook rechtstreeks in Blokmap; een herinnering vervangt de controle van je reservatiestatus niet.

## Gekoppelde organisaties

Onder **Gekoppelde organisaties** zie je met welke onderwijsinstellingen je profiel verbonden is. Klik op **Koppelen**, kies de juiste organisatie en volg de aanmeldstappen van die instelling.

Gebruik deze optie wanneer je met Google bent aangemeld maar voor een locatie ook je instellingslidmaatschap moet aantonen.

## Je aanwezigheid bevestigen

De knop **Open scanner** op je profiel opent de scanner voor een QR-code op de locatie. Lees [Aanwezigheid bevestigen](./checking-in) voor de volledige werkwijze.
