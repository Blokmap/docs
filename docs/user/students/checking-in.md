# Aanwezigheid bevestigen

Sommige zones vragen om je aanwezigheid met een QR-code te bevestigen. Controleer de instructies bij je reservatie en op de locatie.

## Een QR-code scannen

1. Ga naar de locatie en zoek de QR-code van je zone of zitplaats.
2. Scan de code met de camera-app op je smartphone, of open **Mijn Profiel** in Blokmap en kies **Open scanner**.
3. Geef de browser cameratoegang als je de scanner in Blokmap gebruikt.
4. Meld je zo nodig aan met het account waarmee je reserveerde.
5. Volg de aanwijzingen en controleer of de check-in geslaagd is.

Een zonecode hoort bij een hele zone; een zitplaatscode hoort bij een specifieke stoel. Gebruik de code die past bij je reservatie.

## Als scannen niet lukt

Controleer of je de juiste code gebruikt en of je binnen de toegelaten aanmeldperiode bent. Zorg voor voldoende licht en controleer de cameratoestemming in je browser. Je kan ook de camera-app van je telefoon proberen.

Vraag hulp aan de locatiebeheerder als de code ongeldig is of je aanwezigheid niet bevestigd wordt. Een foutmelding betekent niet dat je automatisch bent ingecheckt.
